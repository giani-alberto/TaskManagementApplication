# Task Management Application

A full-stack Task Management web application built to organize daily activities efficiently. This project demonstrates end-to-end development skills, featuring a clean user interface and a robust backend.

## 🚀 Tech Stack
* **Frontend:** Angular, HTML5, CSS3, TypeScript
* **Backend:** C# .NET Web API
* **Data Storage:** Local JSON file (File-based storage system)

## ✨ Key Features
* **CRUD Operations:** Create, Read, Update, and Delete tasks seamlessly.
* **Status Tracking:** Mark tasks as completed or pending, with state persistence.
* **Priority Management:** Assign task priorities (Low, Medium, High) with visual color-coded badges.
* **Dynamic Filtering:** Filter tasks in real-time based on their completion status.
* **Modern UI:** Clean, responsive, card-based interface with hover effects and intuitive controls.

## 🛠️ How to Run Locally

### Prerequisites
* [Node.js & npm](https://nodejs.org/) installed for Angular.
* [.NET SDK](https://dotnet.microsoft.com/) installed for the C# backend.

### Backend Setup (C# API)
1. Navigate to the backend folder.
2. Restore dependencies: `dotnet restore`
3. Run the application: `dotnet run`
4. The API will typically run on `https://localhost:7062` (check your `launchSettings.json`).

### Frontend Setup (Angular)
1. Navigate to the frontend folder.
2. Install dependencies: `npm install`
3. Start the development server: `ng serve`
4. Open your browser and navigate to `http://localhost:4200`.
